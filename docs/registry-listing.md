# Registry listing copy

## Display name

MiniMax H3 Workflow Toolkit

## Publisher

`@minimax3-org` — https://registry.comfy.org/publishers/minimax3-org

## Short description

Dependency-free local utilities for MiniMax H3 prompt building, prompt validation, workflow guidance, and reproducible run summaries in ComfyUI.

## Long description

Build structured audiovisual prompts for T2VA, I2VA, FL2VA, and REF2VA workflows; check temporal, camera, audio, and reference guidance; produce conservative configuration notes; and save portable run summaries. The package makes no network calls and contains no telemetry, model downloads, account login, or paid functionality.
